# 🧑‍💻 Муслiмов Эрбол — Junior Front-end Developer Portfolio

Адаптивный одностраничный сайт-портфолио, выполненный в современном темном дизайне с неоново-зелеными акцентами. Проект демонстрирует базовые навыки веб-разработки, чистую верстку и интерактивность, написанную на чистом JavaScript.

## 🛠 Технологии

Проект написан **без использования сторонних библиотек** и фреймворков:

- **HTML5** (семантическая разметка)
- **CSS3** (Flexbox, CSS Grid, CSS Variables, Media Queries)
- **Vanilla JavaScript** (ES6+)
- **Google Fonts** (шрифт Inter)

## ✨ Особенности и функционал

**JavaScript (Интерактивность):**

- **Мобильное меню:** Бургер-меню, которое плавно открывает навигацию на смартфонах и закрывается при клике на ссылку.
- **Валидация формы:** Проверка полей (имя, email, сообщение) на пустоту и корректность ввода. При ошибке поле подсвечивается красным, а при успехе кнопка меняет текст на "Отправлено! ✓".
- **Плавный скролл:** Плавное перемещение по странице при клике на навигационные ссылки-якоря.

**CSS & Дизайн:**

- **Строгий адаптив:** Сетки перестраиваются от 2 колонок на ПК до 1 колонки на мобильных устройствах.
- **CSS-переменные:** Все цвета (включая неоново-зеленый акцент) вынесены в `:root` для легкой поддержки.
- **Стилизация:** Кастомный мокап редактора кода, карточки проектов с hover-эффектами и аккуратные формы ввода.
